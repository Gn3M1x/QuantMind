后续增加了横向边界，当前实现与最新验收见 [横向边界验收](chart_boundaries.md)。本文下方的69项Python、10项JS及请求计数为中心跟随版本的历史验收；其中“空窗口”用例已更新为到边缘停止。

本轮在现有 Python 3.11 `.venv`、Streamlit 1.66.0、Plotly Python 6.9.0 上实施。已检查安装包，实际前端版本为 Plotly.js 3.7.0。没有修改行情适配器、数据校验、数据库、指标公式、Analysis 或报告计算，也没有执行 Git commit/push。

## 方案

原生 `st.plotly_chart` 提供选择事件回调，没有所需的浏览器连续范围回调。Plotly.js 3.7.0 的 [dragbox 源码](https://github.com/plotly/plotly.js/blob/v3.7.0/src/plots/cartesian/dragbox.js) 明确在拖动过程中发出 `plotly_relayouting`，松手后发出最终范围事件。

采用局部 Streamlit v1 组件，保留 `build_workspace` 和同一 `Analysis`。Plotly.js、控制器、样式和许可证均在 `quantmind/assets/chart/`，本地运行不访问 CDN，也不要求 Node。组件通过 JSON 参数接收已有真实行情与指标；不包含接口访问逻辑，不向 Python 回传高频控件值。

默认左键平移由 Pointer Events 管理：逐次将水平像素位移换算为分类坐标位移，整个手势保持相同跨度；到边缘消费超额位移，反向立即有效；忽略纵向鼠标位移。横向 wheel 也只平移；Ctrl/⌘ + wheel 或捏合缩放围绕指针时间位置进行。普通纵向 wheel 保留页面滚动，图表外不绑定全局 wheel 拦截。

每帧把所有共享横轴和主图价格轴一次性更新。使用 requestAnimationFrame、32ms 间隔和串行 Promise 更新队列；繁忙时只保留最新输入。松手/动量停止后最终校准。程序 relayout 事件有内部重入保护；Plotly 监听器先解绑后重绑，并在组件销毁时清理 DOM 监听器、observer、timer 和动画帧。

原生框选缩放仍可使用。框选预览不是已提交视窗，连续预览事件不重新 relayout；在框选提交后计算价格范围，避免原生 SVG 预览变换反复叠加。原生缩放按钮和手动价格轴变化也通过 Plotly 事件处理。

## 几何定义

分类轴位置为原始真实记录的0-based序号，允许范围边界为小数。可见记录的序号位于范围内，取 ceil(left) 到 floor(right)，并与实际记录相交；高低影线位于该记录中心。不会把未返回的自然日补成行情。

取距离水平中心最近的可见序号，等距时固定取较早一根。C = (high + low) / 2；L/H取可见影线及已显示均线的最低/最高值。R = max(C-L, H-C, abs(C)×0.002, 0.000001)，最终范围为 [C-1.1R,C+1.1R]。均线只扩大对称半幅，不改变蜡烛中心。图例隐藏的均线不参与后续范围计算。

单根/横盘保留最小半幅；横向边界先确定合法窗口，正常浏览不会移入空窗口。空数据防御分支显示没有行情；可见异常值暂停跟随并提示，不删除行情或伪造价格。正常生产数据仍在 Python 入库与分析前校验。成交量、MACD、RSI不使用价格轴算法，RSI保持0～100。

自动跟随默认开启，锁定主图纵向手势。关闭后允许调整右侧价格轴。恢复视图回到当前快捷范围的初始窗口，并开启跟随；新查询/刷新生成新的query UUID，恢复全部窗口。普通均线、副图、标签页与未提交表单编辑保留浏览位置和跟随状态；sessionStorage只保存视窗参数。

## Mac触控板人工验收

1. 打开 `http://127.0.0.1:8501`，查询真实行情，选择1个月或3个月，确认自动跟随开启。
2. 指针置于主图，双指左右滑动并保留惯性，确认K线随时间平移、密度不变、四个面板日期对齐；中心日期的高低影线中点保持在主图垂直中央。
3. 分别浏览明显上涨与下跌区间。确认上下自然跟随，所有可见影线都在图内，屏幕外高低点不撑大范围。
4. 双指捏合缩放，然后继续左右滑动；将指针移到图表外上下滑动，确认页面滚动正常。
5. 关闭跟随，拖动右侧价格轴，确认可手动调整；再平移时纵轴保持手动范围。点击恢复视图，确认回到当前快捷窗口且跟随开启。
6. 切换副图/均线与标签页检查位置保留；提交另一ETF或同ETF新查询，检查位置和跟随重置。

**真实Mac双指手势、触控板惯性与捏合的手感均需要人工验收，本轮自动化没有验证物理硬件。**
