# 交易日期显示修复与UI改版验收

本次在现有项目上修改，使用既有 Python3.11虚拟环境、Streamlit1.66.0、Plotly6.9.0；没有新增运行依赖。

## 问题原因与原始数据核对

- **通过**：直接请求 `ak.fund_etf_hist_sina("sh510300")`，原始3494条，规范化后仍3494条，周末记录0条。抽查本地原始CSV与规范化后的日期一致；缓存三只ETF也没有周末行。
- **通过**：生产代码未使用自然日reindex、前向/零值填充OHLC。原始→清洗→最终浏览器K线的一个月日期完全一致，收盘价在浮点解码精度内一致（最大差约8.9×10⁻¹⁶），绘图传递现有OHLC值。没有通过改价或造行解决显示问题。
- 原因是绘图直接使用datetime，Plotly自动选用连续日期轴，周末及源站未返回日期占据自然日宽度；同时固定`%Y-%m`把一个月内的多个刻度显示成相同年月。

## 实现

- `quantmind/charts.py`按已校验升序的真实日期构造分类轴。分类键是完整YYYY-MM-DD，每条记录一个位置，K线、MA、成交量、RSI、MACD使用相同日期序列；K线与成交量共享横轴。
- 三个月以内标签为MM-DD，更长区间为YY-MM-DD。使用自动刻度和标签别名，随宽度/缩放重新控制密度，悬停使用独立的完整ISO日期。
- 超过3个自然日的相邻记录间隔用细虚线标记，数据说明还可展开全部大于1个自然日的间隔。任何间隔都未被自动分类为休市或交易日缺失；页面明显说明日期完整性尚未严格核验。
- 原生表单增加数据源选择；顶部显示实际已提交ETF、区间、数据截至、来源与缓存状态。5张指标卡、550px主图（75%价格/25%成交量），下方4个标签页；详细限制收起，实际失败和陈旧警告保持可见。
- 背景#0B1220、卡片#111827、强调色#5B8DEF；系统字体、红涨绿跌。Native Streamlit主题和组件承担主要样式，只保留小段布局CSS。
- UI单位核实规则已收紧：旧缓存的“价量关系核验/推断”不视为权威字段定义。只有明确verified/base/evidence元数据才转换为万份、亿份、万元、亿元；当前无法权威核实的来源显示万/亿原始单位（未核实）。这些是数量缩写，原始存储值不变。报告中的单位说明同步收紧。

参考：[Plotly分类轴](https://plotly.com/python/categorical-axes/)、[xaxis刻度与labelalias](https://plotly.com/python/reference/layout/xaxis/)、[Streamlit Plotly配置](https://docs.streamlit.io/develop/api-reference/charts/st.plotly_chart)、[AKShare字段文档](https://akshare.akfamily.xyz/data/fund/fund_public.html)。
